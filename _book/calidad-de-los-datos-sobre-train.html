Capítulo 3 Calidad de los datos (sobre train)

3.1 Valores nulos

nulos <- colSums(is.na(train_df))
nulos <- nulos[nulos > 0]

if (length(nulos) == 0) {
  cat("No se encontraron valores nulos en train.\n")
} else {
  cat("Se encontraron", length(nulos), "columnas con valores nulos:\n")
  print(nulos)
}
## No se encontraron valores nulos en train.

Ninguna empresa de train tiene información faltante en sus estados financieros.

3.2 Filas duplicadas

duplicados <- sum(duplicated(train_df))
cat("Filas duplicadas en train:", duplicados, "\n")
## Filas duplicadas en train: 0

No hay filas repetidas en train, así que no es necesario eliminar duplicados.

3.3 Variables categóricas y cardinalidad

for (c in cat_vars) {
  print(table(train_df[[c]]))
  cat("Cardinalidad:", length(unique(train_df[[c]])), "valores únicos\n\n")
}
## 
##    0    1 
## 5449    7 
## Cardinalidad: 2 valores únicos
## 
## 
##    1 
## 5456 
## Cardinalidad: 1 valores únicos

Net Income Flag vale 1 para prácticamente el 100% de las empresas en train, es decir, no importa si una empresa quebró o no, casi siempre tiene el mismo valor (1). Por lo tanto, es una variable (casi) constante y sería una candidata clara para eliminar antes del modelado. Liability-Assets Flag sí varía, aunque muy poco. Vale la pena revisarla más adelante junto al target, en la sección de análisis bivariado.
